🌌 Nebula Presence
Nebula Presence is a modern, lightweight, and stunning desktop application for managing your Discord Rich Presence.

Built with a beautiful "Galaxy Glass" design, it allows you to completely customize what Discord shows you're doing—whether it's playing a game, working, or just chilling. It uses official Discord IPC protocols, meaning it is 100% safe, requires no injections, and doesn't ask for your Discord account credentials.

✨ Key Features:
Live Preview: See exactly how your rich presence card will look on Discord in real-time before you apply it.
Theme Engine: Choose from 6 premium design systems (Galaxy, Midnight, Aurora, Cyberpunk, Deep Space, Pure Black), pick a custom accent color, and adjust the glass blur intensity.
Custom Timers: Easily set up an elapsed timer ("Playing for...") or a countdown timer ("Time left...").
Profile Manager: Create, duplicate, favorite, export, and import multiple presence presets for different games or moods.
Interactive Buttons: Add up to two clickable buttons to your profile (e.g., "My Twitch", "Visit Website").
System Tray Mode: Minimize the application to your system tray to keep it running smoothly in the background without cluttering your taskbar.
📖 How to Use (Step-by-Step Guide)
To set up your custom status, you'll need a unique "Application ID". You only need to do this setup once.

Step 1. Get an Application ID
Go to the official Discord Developer Portal
.
Click the "New Application" button in the top right corner.
Give your application a name. Note: This name is exactly what will be displayed next to "Playing" on your Discord profile (e.g., Cyberpunk 2077, Visual Studio Code).
Once created, copy the long number under "APPLICATION ID" on the General Information page.
Step 2 (Optional). Add Art Assets
In the Developer Portal's left sidebar, navigate to Rich Presence -> Art Assets.
Click Add Image(s) under the "Rich Presence Assets" section. Upload your images and give them simple, memorable names (e.g., logo, level1).
Click "Save Changes". (Pro Tip: Alternatively, inside Nebula Presence, you can just paste a direct https:// image link from the internet instead of uploading assets to Discord!)
Step 3. Set Up Nebula Presence
Open Nebula Presence and go to the Presence Editor tab.
Paste the number you copied into the Application ID field.
Fill in the Details (Line 1) and State (Line 2) text fields.
Under Image Key / URL, type the exact names of the images you uploaded to the Developer Portal, or simply paste direct image URLs.
Customize your timers and add button links if desired.
Step 4. Launch!
Click the Start Presence button below the Live Preview window. Congratulations! Your friends can now see your highly customized, beautiful status on Discord!
